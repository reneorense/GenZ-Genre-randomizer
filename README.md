# GEN Z — After Hours / 3.0

This dist folder is the complete website. No build or installation is required.

## Upload to your existing GitHub repository
1. Extract this ZIP.
2. Open dist. Select its contents, including the intact src and public folders.
3. Place those contents at the repository root, alongside index.html. Accept replacements.
4. Commit and push. Keep your existing GitHub Pages branch/root setting.
5. Refresh the live website after deployment. If the previous design remains, hard-refresh.

Do not flatten the folders. Do not upload the ZIP itself as the website.

## Files
- index.html: page layout
- src/styles/night.css: After Hours theme and responsive layout
- src/main.js: interactions
- src/data: existing catalog
- src/components, src/services, src/state, src/motion: existing modules
- public/favicon.svg: icon

## Changes
Dark charcoal theme with genre-colored lighting; shuffle directly beneath the vinyl; current genre on the deck; floating return-and-shuffle control; enhanced vinyl tilt, spin, reveal glow and decorative equalizer; record-sleeve browsing treatment. Existing catalog, crate, search, artist links and sharing retained.

Quick reveal skips shuffle animation. System reduced-motion preferences are respected. Sound is an optional synthesized effect, not music playback. Saved records stay in this browser on this website.

## Validation
Browser checked on desktop and in 390px / 320px viewport frames. Exercised shuffle, saved crate, search/no-results and mobile return-and-shuffle. Checked local references and JavaScript syntax. Physical-device and external music-service playback testing were not performed.
